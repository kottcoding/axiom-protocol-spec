# Axiom System Overview

## Layer Model

```text
Applications / Wallets / AI Agents
        ↓
Axiom Agent Layer
        ↓
Pulse Micropayment Layer
        ↓
Axiom Core Layer 1
        ↓
Guardian Validator Network
```

## Responsibilities

### Application Layer
Wallet UI, developer SDK, DApps, explorer, testnet dashboard.

### Axiom Agent Layer
AI session keys, spending limits, whitelisted contracts, audit logs, emergency revoke.

### Pulse Layer
Micropayments, streaming payments, AI-to-AI payments, batch settlement to Layer 1.

### Axiom Core Layer 1
Monetary rules, consensus, validator registry, state transition, settlement finality.

### Guardian Validator Network
Guardian Core Nodes, Citizen Validators, Mobile Guardians, Passive Witnesses.
