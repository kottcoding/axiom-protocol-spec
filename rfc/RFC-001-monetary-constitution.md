# RFC-001 Monetary Constitution
## Abstract
Axiom defines immutable constitutional monetary rules enforced by decentralized consensus.

## Core Monetary Rules
- Maximum Supply: 100,000,000 AXM
- Smallest Unit: 1 AXM = 100,000,000 AXI
- Emission Rate: 1,000,000 AXM annually
- Emission Duration: 100 years
- Post-emission inflation: 0%

## Emission Equation
```text
annual_emission = 1,000,000 AXM
block_reward = annual_emission / yearly_blocks
```

## Governance Restrictions
Governance cannot modify:
- hard cap
- emission schedule
- founder allocation
- constitutional rules

## Fee Economy
```text
TotalFee = BaseFee + PriorityFee
```
