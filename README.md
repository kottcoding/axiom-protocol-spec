# Axiom Protocol Specification

Axiom is a decentralized constitutional monetary protocol designed for humans, applications, and AI economies.

## Repository Structure

- `/rfc` → Constitutional RFC documents
- `/specs` → Technical specifications
- `/diagrams` → Architecture diagrams

## Core Goals

- Decentralization
- Immutable monetary policy
- AI-compatible economy
- Low-energy validation
- Micropayment support
- Long-term validator sustainability
