# Testnet v1 Scope

## Included

- AXM / AXI unit support
- fixed emission simulator
- basic transaction model
- dynamic fee market
- validator registry
- simple block production
- founder vesting simulation
- faucet
- explorer placeholder
- basic wallet integration

## Excluded

- bridge
- full AI autonomy
- full Pulse production network
- complex governance
- mainnet token value

## Goal

Testnet v1 should prove core protocol mechanics, not final production economics.
