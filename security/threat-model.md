# Axiom Threat Model

## Threat Categories

### Monetary Threats
- unauthorized mint
- hidden inflation
- emergency supply override

### Consensus Threats
- double signing
- validator cartel
- censorship
- invalid finality

### Network Threats
- spam
- eclipse attack
- denial of service

### Smart Account Threats
- key compromise
- malicious approval
- phishing

### AI Agent Threats
- runaway spending
- malicious tool use
- compromised session key
- unauthorized contract call

## Security Objective

Axiom must fail safely and limit damage when one layer is compromised.
