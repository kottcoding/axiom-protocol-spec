# Audit Checklist

## Before Testnet v1

- monetary constants reviewed
- emission simulator tested
- fee simulator tested
- founder vesting logic tested
- transaction replay protection tested
- state transition deterministic
- validator slashing evidence tested
- AI permissions tested
- no admin mint path
- no protocol freeze key
- reproducible builds

## Before Mainnet

- independent protocol audit
- cryptography audit
- economic simulation
- adversarial testnet
- bug bounty
- multi-client review
- community review
